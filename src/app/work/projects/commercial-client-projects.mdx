## Overview

A curated collection of commercial projects delivered for real clients — spanning full-stack ordering systems, conversion-focused landing pages, and backend automation integrations. Each project was built with React.js, Tailwind CSS, and deployed on Vercel with SEO optimization.

## Projects Delivered

### i-Rabian Kabab — Restaurant Ordering System
A full-stack online ordering platform with a custom-built management dashboard for the restaurant team. Features include:
- Menu management and real-time order tracking for staff.
- Customer-facing ordering UI with cart and checkout flow.
- Admin dashboard for order management and sales reporting.

### Quetta Chemical Services — Business Landing Page
A performance-optimized landing page focused on B2B lead conversion for an industrial chemicals company. Features include:
- SEO-optimized structure with fast Core Web Vitals scores.
- Clear service sections and lead capture forms.
- Responsive design optimized for both mobile and desktop.

## Automation Work

- **AI Automation**: Built custom AI-driven automation workflows for client business processes.
- **WhatsApp API Bots**: Developed WhatsApp Business API bots for customer support and order notification automation.
- **Webhook Integrations**: Connected third-party services via webhooks for real-time data sync between platforms.

## Technologies Used

- **React.js & Next.js** — Component-driven frontends with server-side rendering for SEO.
- **Tailwind CSS** — Rapid, consistent UI styling.
- **Vercel** — Fast, global deployment with automatic HTTPS and CDN.
- **WhatsApp Business API** — Automated messaging and notification flows.
- **JWT Auth** — Secure authentication for admin and user roles.
- **Clean Architecture** — Separation of concerns across data, business logic, and presentation layers.

## Outcome

All client projects were delivered on time and are live in production. The restaurant ordering system streamlined i-Rabian Kabab's operations significantly, while the chemical services landing page improved lead capture from organic search.
